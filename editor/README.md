# 에디터 프로토타입

`.mrc` 를 칠하고, 가정(`?`)을 돌려 줄마다 결과를 그린다. 아주 작은 단위만 한다.

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # bun test: 토크나이저 · 모양 추론 · 가정 실행
```

## 되는 것

열면 예제가 이미 돌고 있다. 오른쪽 패널 없이 전부 글자 자리에서 보인다.

- **블록 미리보기**: `model` → 지금 데이터 표, `interface`·`component` → 실제 화면(버튼·입력이 진짜로 동작), `system` 머리 → `▶ 사건` 단추. 전부 같은 세계 하나를 보고, 누르면 같이 바뀐다. 실패는 롤백 후 실패 사건까지 흐른다. `↺ 처음 값` 으로 가정 상태로
- **미리보기 ↔ 코드**: 미리보기 요소에 마우스를 올리면 그 소스 줄이 빛나고, 누르면 그 줄로. 커서가 선 줄의 요소는 미리보기에서 파랗게
- **렌즈**: 커서 아래 이름의 종류·타입·지금 값·쓰는/읽는 system 이 그 줄 끝에. 타입 위면 바꿀 후보, 숫자 위면 끌기 안내
- **블록 강조 · 참조**: 커서 블록은 카드처럼, 안쪽 블록은 파란 선. 블록 머리에 `→ 쓰는 블록` `← 쓰는 쪽` 칩, 왼쪽 여백에 참조 선
- **쓰면서 배우기**: 맨 위 띠에 지금 자리에서 할 수 있는 것, `/` 로 같은 목록(한글로 찾기 됨, 고르면 `Tab` 으로 칸 채우기). 줄 끝에 남은 칸이 흐리게. 단어에 마우스를 올리면 설명과 예시
- **자동 정리**: `↵` 는 블록 머리면 안으로, 빈 줄이면 밖으로. 줄을 떠나면 model 칸·예시 데이터 칸이 세로로 맞춰진다(`⌘S` 전체). 괄호·따옴표 자동 닫기
- **숫자 끌기**: 숫자를 좌우로 끌면 값이 바뀌고 미리보기가 따라 바뀐다
- **결과 · 기대 · 모양**: 계산 칸, `check`, 보간 문자열 결과를 줄 끝에. `!` 기대가 틀리면 빨갛게. system 의 읽기·쓰기·실패 추론
- **키**: `⌥←/→` 토큰 이동, `⌘↑/↓` 선택 넓히기·좁히기, `⌥↑/↓` 블록 옮기기·숫자 ±, `F12`·`⌘클릭` 정의로, `F8` 같은 이름 다음, `⌘P` 이름으로 가기, `⌘/` 단축키

## 아직 안 되는 것

- 그 자리에서 묶기·풀기 (`⌘G`), 구멍에서 선언 만들기
- `sample` 블록 실행, 대안 값 토글 (`? A | B`)
- 문서를 고치면 미리보기 세계는 가정 값으로 다시 시작한다
- 성능: 키 한 번마다 전체 분석 (DX 먼저)
- 그래프 보기
- 에러 메시지. 지금은 모르는 문법을 조용히 넘긴다

## 구조

```
src/lang/tokenize.ts   렉서 + 줄 분류 (하이라이트 토큰)
src/lang/expr.ts       식 파서
src/lang/analyze.ts    개요 트리 → 가정 세계 → 모양 추론 → 가정 실행 → 줄 주석
src/lang/sim.ts        미리보기 세계: 사건 → system 실행 → 롤백 → 실패 사건
src/ui/preview.ts      블록 미리보기 (화면 · 표)
src/ui/inline.ts       렌즈 · 블록 강조 · 엿보기 · 남은 칸 · 블록 머리 단추 · 경로 띠
src/ui/learn.ts        단어 설명 · 자리별 할 수 있는 것 · 남은 칸
src/ui/format.ts       ↵ · 칸 맞춤
src/ui/arcs.ts         참조 선 · 숫자 끌기
src/main.ts            CodeMirror 6 조립
```
